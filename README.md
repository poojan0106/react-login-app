# Beautiful Login Page

A stunning, modern login page built with React and Vite, featuring glassmorphism design, animated gradients, and premium aesthetics.

## ✨ Features

- **🎨 Modern Glassmorphism Design** - Frosted glass effect with backdrop blur
- **🌈 Animated Gradient Background** - Smooth color transitions with floating shapes
- **💫 Smooth Animations** - Hover effects, focus states, and loading spinner
- **📱 Fully Responsive** - Optimized for mobile, tablet, laptop, and desktop
- **⚡ Fast & Lightweight** - Built with Vite for optimal performance
- **🎯 Premium Typography** - Using Google's Inter font family

## 🚀 Quick Start

### Installation

1. Clone the repository
2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open `http://localhost:5173/`

## 📦 Build for Production

```bash
npm run build
```

Production files will be in the `dist/` folder.

## 🎨 Responsive Breakpoints

- **Mobile** (< 480px): Compact design
- **Tablet** (768px - 1023px): Medium layout
- **Laptop** (1024px+): Enhanced spacing
- **Desktop** (1440px+): Maximum size

## 🛠️ Technologies

- React + Vite
- CSS3 with animations
- Google Fonts (Inter)

## 📝 Customization

Edit colors in `LoginPage.css` and form fields in `loginPage.jsx`.

---

**Note**: This is a frontend-only login page. Backend authentication needs to be implemented separately.
